# 🌌 Space Weather IKI RAN (HACS)

Интеграция для Home Assistant, предоставляющая детальные данные о космической погоде напрямую от **Института космических исследований РАН**. Включает уникальную анимированную карточку, которая меняет свой фон в реальном времени в зависимости от уровня магнитных бурь.

## ✨ Особенности

* **Два стиля отображения**: Универсальная UI-карточка включает сразу два макета (переключаются в визуальном редакторе Lovelace одним кликом):
  * *Современный (Вкладки)* — компактный дизайн, идеально подходящий для мобильных устройств.
  * *Классика (Список)* — развернутый вид со всеми данными на одном экране, отлично смотрится на дашбордах планшетов и ПК.
* **Пользовательские названия**: Возможность переопределить имя города прямо в настройках карточки (например, назвать локацию «Дом» или «Дача»).
* **Живые видео-фоны**: 6 эксклюзивных анимированных фонов (`.mp4`), плавно переключающихся при изменении индекса Kp (от спокойного состояния до экстремальной бури G5).
* **Полная локализация**: Названия городов и статусы активности отображаются на чистом русском языке.
* **Оптимизация для мобильных устройств**: Карточка корректно работает в Safari и официальном приложении Home Assistant благодаря встроенным фиксам регистрации элементов и плавному скрытию вкладок.
* **Легкая установка**: Полная совместимость с HACS для автоматического управления ресурсами и обновлениями.

### Шаг 1: Добавление в HACS

Вы можете нажать на кнопку ниже, чтобы автоматически открыть страницу установки в вашем Home Assistant:[![Open your Home Assistant instance and open a repository window in HACS.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=Eugen417&repository=HA_xras_space_weather&category=Integration)

Или выполните установку вручную:

1. Откройте **HACS** -> **Integrations**.
2. В верхнем меню нажмите `...` -> **Custom repositories**.
3. Вставьте URL `https://github.com/Eugen417/HA_xras_space_weather` и выберите категорию **Integration**.
4. Нажмите **Install**.

Отличный черновик для документации (Readme)! Чтобы инструкция была максимально полной и понятной (особенно для тех, кто будет устанавливать интеграцию впервые), я логически выстроил шаги и **добавил подробное описание работы с нашим новым визуальным редактором карточки**.

Вот готовый, дополненный вариант, который можно смело копировать в инструкцию:

### Шаг 2: Настройка интеграции

1. Перейдите в **Настройки** -> **Устройства и службы** -> **Добавить интеграцию**.
2. Найдите в поиске **Космическая погода (ИКИ РАН)**. *(Примечание: Если интеграция не появляется в поиске, убедитесь, что вы полностью перезагрузили Home Assistant после копирования файлов в папку `custom_components`)*.
3. Выберите ваш город из предложенного выпадающего списка. Этот город будет использоваться для автоматического создания датчиков и расчета вероятности полярного сияния именно в вашей локации.
4. После успешного добавления интеграции **обязательно очистите кэш браузера** (нажмите `Ctrl + F5` на клавиатуре) и/или мобильного приложения HA (левое меню -> ваш Профиль -> пролистать вниз -> *Очистить кэш интерфейса*). Это необходимо, чтобы система подтянула новые скрипты карточки.

### Шаг 3: Добавление карточки на дашборд

1. (Для проверки) Зайдите в **Настройки** -> **Панели управления** -> **Ресурсы**. Убедитесь, что ресурс `/api/xras_sw_static/space-weather-card.js?v=1xxxxxxxxxxxxxx` был добавлен автоматически.
2. Перейдите на целевую панель (дашборд), куда хотите добавить карточку.
3. Нажмите на три точки в правом верхнем углу и выберите **Редактировать дашборд**.
4. Нажмите синюю кнопку **Добавить карточку** (в правом нижнем углу).
5. Найдите в предложенном списке карточек **Космическая погода** и кликните по ней.
* *Альтернативный способ:* Прокрутите список в самый низ, выберите карточку **Вручную** (Manual) и просто вставьте код:
```yaml
type: custom:space-weather-card

```
6. В открывшемся визуальном редакторе настройте внешний вид:
* **Стиль отображения:** Выберите компактный современный вид (**Вкладки**) или развернутый вид (**Классика**). Карточка мгновенно поменяет свой дизайн в окне предпросмотра.
* **Название города:** При желании, вы можете переопределить отображаемое на карточке имя города. Если оставить поле пустым, будет использоваться название из настроек интеграции.
7. Нажмите **Сохранить** и нажмите "Готово", чтобы выйти из режима редактирования дашборда.

*Карточка автоматически найдет все сенсоры и подставит актуальное видео в шапку.*

## 🎥 Медиа-контент

В состав репозитория (папка `www`) уже включены 6 анимированных файлов:

* `normal.mp4` — Состояние покоя.
* `g1.mp4` – `g5.mp4` — Визуализация магнитных бурь разной интенсивности.

## 🛠 Устранение неполадок (Safari/iOS)

Если на устройствах Apple карточка не отображается (ошибка `Custom element doesn't exist`):

1. Зайдите в **Настройки** -> **Панели управления** -> **Ресурсы**.
2. Проверьте наличие ресурса `/api/xras_sw_static/space-weather-card.js?v=1xxxxxxxxxxxxxx`.
3. В мобильном приложении выполните: `Настройки` -> `Приложение Companion` -> `Отладка` -> `Очистить кэш интерфейса`.
